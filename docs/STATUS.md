**Godot 4(GDScript)に移行した直後。** 2026-11-16 に Unity 版を Godot に移した(理由はエンジンではなく再開しやすさ。Shioka が止まっていた原因は素材づくりの手間)。今後は `godot/` が正で、Unity のプロジェクトは参照用。Godot 版の内容は Unity 版と同じ(Title、キャラ選択、Training、KeyConfig)。違う点と未確認の点は [UNITY_TO_GODOT.md](UNITY_TO_GODOT.md)。操作感の最終確認はユーザーの実機での確認待ち。

それ以前から続く段階は、**基本システム・調整の環境・開発を続けられるかを確かめている段階。** キャラクター「ぁゎり」は仮のキャラクターとして作り始めたもので、技もグラフィックも仮。せっかくなので、そのまま採用する見込み。(2026-10-29 ユーザー確認)

## できること

- **Training(練習モード)**: 2人の「ぁゎり」で、地上・空中の通常技、投げ、移動、ダッシュ、直前ガード、FD、TRC、押し返し、TG を使った攻防ができる。HP・TG の設定、ダミーの動作設定、録画と再生がある。→ [spec/training.md](spec/training.md)
- **画面の流れ**: Title → Player 選択 → Title、Training → CPU 選択 → Training。Option(KeyConfig)は Title と Training の両方から開ける。→ [spec/flow-and-save.md](spec/flow-and-save.md)
- **入力**: 9つの攻撃枠と修飾キー T1 による同時押し。KeyConfig で割り当てを変えて保存できる。→ [spec/input.md](spec/input.md)
- **調整**: 技・動作・共通パラメータは `godot/data/*.json` を直接編集する。→ [guides/godot.md](guides/godot.md)。Unity 版にあった Inspector とシーン上のハンドルによる編集の道具は、Godot には移していない。

## 値の状態

- **技の値は全体的に未調整。** v0.1 の検証・調整の対象は、意図的に弱中強パンチ(5LP/5MP/5HP: 260/360/460)だけにした。これも仮の値。ほかの技(キック、しゃがみ、空中: 60〜135程度)は旧仕様の値を残した未校正の領域で、この差を最終的な性能として意図したものではない。(2026-10-29 ユーザー・Dot 確認)
- 弱P(5LP)は、発生6F・持続3F・硬直10F、画像は10枚で計19F(ユーザーが調整した値。これも最終ではない)。
- 5HK は、データ上は 20+6+30=56F だが、Unity 版でも Godot 版でも全体は 57F になる(時間を32ビットの小数で足していく誤差。Godot 版は Unity 版と同じになるように合わせた)。
- 空中の通常技は jLK・jMK・jHP・jHK・j2HK の5つ。空中の LP・MP は何も出ない。3HK は足払い(下段)。
