# 実装状況と未決

2026-10-29 時点(コード `106c62f` 時点を確認)。

## できること

- **Training(練習モード)**: 2人の「ぁゎり」で、地上・空中の通常技、投げ、移動、ダッシュ、直前ガード、FD、TRC、押し返し、TG を使った攻防ができる。HP・TG の設定、ダミーの動作設定、録画と再生がある。→ [spec/training.md](spec/training.md)
- **画面の流れ**: Title → Player 選択 → Title、Training → CPU 選択 → Training。Option(KeyConfig)は Title と Training の両方から開ける。→ [spec/flow-and-save.md](spec/flow-and-save.md)
- **入力**: 9つの攻撃枠と修飾キー T1 による同時押し。KeyConfig で割り当てを変えて保存できる。→ [spec/input.md](spec/input.md)
- **調整**: 技・動作・共通パラメータを Unity の Inspector とシーン上のハンドルで編集し、明示的に保存できる。→ [guides/editing.md](guides/editing.md)

## まだないもの・未決のこと

- **キャラクター**: 実装済みは「ぁゎり」だけ。選択画面のほかの枠は未実装。
- **技**: D1〜D3 の技の割り当て。Mania の追加効果とコスト。後方空中ダッシュ(画像はあるが仕様が未決)。
- **戦闘システム**: TG の獲得、FD のコスト、コンボ補正、ダウン・壁・バウンド・受け身、硬直がマイナスになったときのボーナス、暗転停止の詳細。
- **モード**: 対戦(Online の Rank、Exhibition、Arcade、VS CPU)は表示だけで未実装。対戦履歴は保存の仕組みだけある。
- **見た目**: 前歩きの 4枚×4F は作業上の暫定値。弱P(5LP)の画像の拳と攻撃判定の先端がずれている(判定のほうが約0.43m長い)。タイトル画面のアートは未完成。
- **調整のしかた**: Play 中に調整値を試す機能は、提案だけで未承認。今は Play を止めて編集し、明示的に保存する。
