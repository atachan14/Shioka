# コンセプト

Shioka は「真にオモロイ格ゲー」の略。

## 目指すもの

格闘ゲームがほかのジャンルより優れている点は、**駆け引き・アクション・キャラ表現**の3つ。今の格闘ゲームは、固定フレームを使ったコンボやセットプレイのパズル的な面が強調され、アクションゲームとしての可能性を活かしきれていない。パズル的な面も格ゲーの面白さだが、ほかのジャンルでも代わりがきく。

Shioka は、その場の状況に応じた**即興的なアクション**が成り立つ格闘ゲームを目指す。

## 中心になる考え方

- **ヒットとガードの間をグラデーションにする。** 攻撃判定には攻撃の強さ、食らい判定には防御の強さを持たせ、その差で、ヒットか、ガードに近い当たり方か、どれだけ硬直するかが決まる。同じ技を同じように当てても、当てたフレームやゲージの状況で、その後の展開が変わる。
- **テンションゲージ(TG)が攻防の強さに効く。** ゲージは100%を超えることも、マイナスになることもある。使い続けることはできるが、マイナスになると攻撃も防御も弱くなる。
- **硬直をキャンセルできる。** 食らい硬直を含め、残りの硬直に応じたゲージを払って行動をやり直せる(TRC)。
- **タイミングの良さを段階的に評価する。** 直前ガードなどを「成立/不成立」ではなく、タイミングに応じた強さで扱う。
- 攻撃中の防御の強さも技ごとに決められるので、強いアーマー・弱いアーマーを持つ技を作りやすい。差し合いは、発生の速さだけでなく、アーマー前提の読み合いになる。

具体的な式と現在の扱いは [spec/combat.md](spec/combat.md)。

## 初期案のうち、今は採用していないもの

初期資料にはあるが、現在の仕様とは違うもの。復活させるかどうかは未決で、勝手に戻さない。

- 初期のゲージによる強さの補正式(ゲージ1%につき強さ+1など)、ガードクラッシュ・ガードブレイク、直前ガードの初期の数値。現在の式は別([spec/combat.md](spec/combat.md))。
- キャンセルの旧名称(真どこでもキャンセル/SDC)と例示のコスト。現在の名前は TRC。
- 「コマンド入力なし(レバー入れ攻撃のみ)」「3対3とアシスト」「テンションレベルによるゲージ増加量の補正」。将来案として残っているだけで、確定した仕様ではない。
