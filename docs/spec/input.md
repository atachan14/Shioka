# 入力

根拠はコード(`Runtime/Input/`)と `調整Data/共通System/Resources/TrainingInputConfig.asset`、キャラの `AwariCharacter.asset`。

## 攻撃の9枠とキャラの技

物理的なボタン(枠)と、キャラの技は分けて持つ。枠は全キャラ共通で、どの枠にどの技を割り当てるかはキャラごとに決める。

| 枠 | ぁゎりでの表示 | 技 |
|---|---|---|
| A / B / C | D1 / D2 / D3 | 未割り当て(押しても何も出ない) |
| J / K / L | LP / MP / HP | 弱・中・強パンチ |
| X / Y / Z | LK / MK / HK | 弱・中・強キック |

- しゃがみ・空中など、方向や状態によって出る技は変わる(例: しゃがみ中の LP は 2LP)。
- **Hold** は投げ(内部名 Throw)の表示名。**Delirium** は専用のボタンではなく、暗転を含む TG 消費技のカテゴリー。**Mania** は押しっぱなしで使う修飾。追加の効果は未決。

## 既定の割り当て

| 操作 | キーボード | パッド |
|---|---|---|
| A / D1 | U | T1 + □ |
| B / D2 | I | T1 + △ |
| C / D3 | O | T1 + R1 |
| J / LP | J | □ |
| K / MP | K | △ |
| L / HP | L | R1 |
| X / LK | M | × |
| Y / MK | , | ○ |
| Z / HK | . | R2 |
| Hold(投げ) | H | T1 + ○ |
| Mania | どちらかの Shift | L2 |
| TRC | ; | T1 + R2 |
| Dash | Space | T1 + × |
| Record(録画) | R | L3 |
| Play(再生) | P | R3 |
| Reset | どちらかの Ctrl | なし |
| Options | Esc | Options |

- 移動は WASD / 方向キー / スティック。T1 = L1、T2 は未割り当て。
- メニューでは、決定 J / ○、取消 K / ×。

## 同時押し(T1)の規則

- 同時押しの成立を待つ猶予はない(以前の30ms・2Fの待ちは廃止)。通常の先行入力(10F)と発生は変わらない。
- T1 だけを押しても何も起きない。T1 とボタンが同じフレームなら、同時押しの操作だけが出る。
- ボタンを先に押した場合、その通常攻撃はすぐ出る。後から T1 を押すと、その時点で同時押しの操作が1回新しく出る。先の通常攻撃は取り消さない。どちらが実行されるかは、通常のキャンセル・先行入力の規則で決まる。
- 押しっぱなしでは連発しない。T1 を離しても通常攻撃は出ない。どちらかを離して押し直せば、新しい同時押しになる。
- フォーカスが外れたとき、機器が外れたときは、その機器の状態をリセットする。
- メニュー・Training の操作と戦闘の入力は分ける。メニューを閉じたときのボタンが戦闘に漏れない。
- 録画と再生は、物理キーではなく、論理的な枠と Mania の状態を記録する。

## KeyConfig(キー設定)

- 入口: Option → KeyConfig。「基本キー設定」は全キャラ共通の物理入力、「ぁゎり」はキャラの技と枠の対応。
- 行を選んでキーかボタンを入力する。同じキーなら解除、ほかの1行と重なるなら確認して入れ替える。複数の行と同時に重なる登録は拒否する。T1/T2 だけでは同時押しの登録にならない。方向入力は固定。
- 変更は下書き。Save で保存、Cancel・戻る・閉じるで破棄。Defaults(既定に戻す)も Save するまでは下書き。
- 保存先: `Application.persistentDataPath/Profiles/KeyConfig-v1.json`。既存のファイルは `.bak` を残して置き換える。壊れている・足りない・知らないバージョンのときは既定値を使い、元のファイルは残す。
- 2人目用のデバッグ用キーボードと機器の割り当て UI はない。
