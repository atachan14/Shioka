# 戦闘(接触・TG・ガード・押し返し)

暫定仕様(v0.1)。バランスの最終値ではない。根拠はコード(`Runtime/Battle/Combat/CombatV01Formula.cs` ほか)と共通パラメータのアセット。

## 用語

| 記号 | 意味 |
|---|---|
| A | 攻撃の強さ。当たった攻撃判定(HitBox)の値に、位置と持続による補正をかけたもの |
| D | 防御の強さ。当たった食らい判定(HurtBox)の値に、位置の補正をかけたもの(0以上) |
| TG | テンションゲージ。マイナスも100超えもある |
| H | 当たりの強さ。下の式で計算する |
| B | 耐える強さ。今は B = D |

## 当たりの判定

接触の解決の前に、両者の TG をその時点の値で固定する。同じフレームの接触は、どちらも解決前の値を使う。

```
M(T) = 1 + T/200                 (T >= 0)
       1 / (1 + |T|/100)         (T < 0)
H = A × M(攻撃側TG) / M(防御側TG) / (1 + D/100)
```

- A と D に TG を足すのではなく、倍率として効く。
- 食らい判定は、優先度のいちばん高いものから選ぶ。その中で重なる攻撃判定のいちばん弱い A を使い、同じ優先度どうしでは H が最大になるものを採用する。

| 状況 | 結果 |
|---|---|
| 方向・姿勢が合ったガード | **Guard**(H に関係なくガードになる。ガードブレイクはない) |
| それ以外で H ≦ B | **Block**(元の動作を止めて、後で再開する) |
| それ以外で H > B | **Hit**(動作を中断させる) |

判定には、丸める前の H と B を使う。

## 硬直・ヒットストップ・ダメージ

- **基本の硬直**: H/10 F。Guard なら直前ガードの分を引く。最後に端数を切り上げる。0以下は0(マイナスになったときのボーナスは未実装)。
- **ヒットストップ**: `ceil(A × M(攻撃側TG) / M(防御側TG) / 40)` F。H ではなく A を使う。両者が止まる。止まっている間、行動・硬直・押し返しは進まないが、入力と直前ガードの時計は進む。止まっている間に同じ接触で何度も当たらない。
- **ダメージ**: H × 技ごとの倍率。Hit は倍率1(既定)、Guard と Block は削りの倍率0.1(既定。技ごとに変えられる)。FD 中は削りなし。HP とダメージは小数のまま持つ。削りでも KO する。基準の HP は 2300。
- 例: TG が同じ、D=100 のとき、A=260/360/460 なら H=130/180/230、基本の硬直13/18/23F、ヒットストップ7/9/12F。

## 直前ガード(JG)

- 新しくガード方向を入れた瞬間から、経過フレーム(age)を数える。同じ方向を押し続けても更新しない。ガード以外の方向で解除。向きが反転しただけでは更新しない。
- 引く量: 通常は age 0〜29F で `10 - floor(age/3)`。ガード硬直が続いている間は age 0〜19F で `10 - floor(age/2)`。範囲外は0。
- ヒットストップ中も age は進むので、次の攻撃が来る直前に入れたガードほど強い。

## FD と押し返し

- **FD**: Mania を押しながら、相手から見て後ろ方向(1/4/7)。空中・姿勢・行動の制限は通常のガードと同じ。
- **押し返しの量** K = H × 技ごとの係数(既定0.001m)。Guard は K、Block は K/3、Hit は 1.2K。
- ヒットストップの後、10戦闘フレームかけて、最初は速くだんだん遅くなるように動く。硬直が先に終わっても、残りの押し返しは続く。
- j = 直前ガードで引いた量/10 として、通常の Guard で自分が下がる量は K(1 − 0.4j)。FD のときは自分は K 下がり、攻撃側を K × 0.2(1 + 1.5j) 押し返す。FD でも直前ガードの硬直減少は効く。
- 壁でのダウン免疫は将来の要件。壁でのダウンそのものが未決。
