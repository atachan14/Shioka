# Training(練習モード)

根拠はコード(`Runtime/Training/`)と旧 docs の Training の記録。

## 設定できること

- **HP**: 設定値にできる。最後に実際のダメージを受けてから約3秒後に自動で回復する。硬直などが続いている間は待つので、コンボの途中では回復しない。
- **TG**: 符号付きで設定できる。「固定」にすると増減そのものが止まる。設定・Reset で指定値に戻る。
- **ダミー**: ガード、FD、常時 FD、直前ガードの強さの指定。
- **表示**: 入力履歴、フレームバー、レベル表示などの切り替え。

TG の獲得と FD のコストは未実装(TRC のコストは既にある)。

## 録画と再生

- Record(R)で、3秒のカウントの後、Player の操作をダミーに切り替えて録画する。最大10秒、1枠だけ、メモリ内に保存する。
- Play(P)で、録画したダミーの入力を1回再生する。
- メニューのキー自体は戦闘の記録に入れない。
- Reset(Ctrl)で、設定した HP・TG・位置に戻す。

## 画面

- カメラの横幅は6〜10m、16:9。画面の端で体を止める(OS のウィンドウの大きさを固定するわけではない)。
- キャラクターは、Player と CPU の確定した選択を使う([flow-and-save.md](flow-and-save.md))。今は2人とも「ぁゎり」で、同じ Prefab と同じ調整データを使う。入力の主体と左右の向きは別。
