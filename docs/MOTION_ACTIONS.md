# Individual motion actions: first milestone

Open Assets/Shioka/調整Data/Fighter/Awari/Move/Idle/Idle.asset or Move/ForwardWalk/ForwardWalk.asset. Select the asset outside Play. The Inspector edits a private draft: poses contain sprite, integer hold frames (60Hz), local-forward X/up Y visual offset in meters, and hurt geometry by stable part ID. The preview shows the calibrated sprite, ground and hurt outlines; Mirror left previews facing. Save same asset explicitly adopts the draft; Cancel/reload discards it. Closing selection discards unsaved edits. Inspector does not save in Play.

AwariCharacter references these assets. The old idle/forward sprite fields are cleared for adopted Awari; Scene sprite fields are compatibility caches populated from character data, not another authoring source. Each asset starts with one existing approved held pose, zero offset, stable part0 center(0,0.775), size(0.52,1.55). No new art, interpolation or walk cycle was imported. Animation changes never change walking speed, acceleration or jump/dash data.

Frame holds loop or clamp at the final pose; count need not divide any movement duration. The existing combat timer advances playback, pauses during hitstop/Block, and resets action playback on transitions. Offsets mirror in X; both fighters share the character references. Hurt geometry overrides only existing part IDs; defense/priority/correction remain in Hurtboxes.asset. Unknown or omitted IDs fall back to existing geometry. Do not rename part IDs in a motion asset. Idle/ForwardWalk are eligible only when standing grounded, unguarded, and outside attacks/dash/retreat. Other states keep existing behavior.

The asset Inspector now includes Open Scene visual editing: cyan position handle edits the sampled pose image offset, green box edits the chosen hurt index. Preview objects are temporary HideAndDontSave, contain no Fighter/combat, and are destroyed on close/deselection or entering Play. Undo affects draft only; Save same asset writes the same source asset. The older Ground/Air/Throw scene remains separate. Native mouse dragging has not been physically verified; preview creation/cleanup and save/reload are automated checks. Other action assets, per-skill SOs, consolidated performance data and Fighter Prefab are not implemented by this step.
